# beatscope

**Every hit. On the line.**

A monochrome, FL Studio-style audio visualizer that runs in the browser. Load a track and it draws a dense waveform history, a triggered oscilloscope and a log spectrum, with bloom and grain on top and a hard full-frame invert on big kicks.

## Run

Open `index.html` in a browser (or serve the folder), then drop an audio or video file onto the page.

| Key | Action |
| --- | --- |
| space | play / pause |
| ← → | seek 5s |
| click/drag top bar | scrub |
| I | toggle kick inverts |
| G | toggle glow |
| F | fullscreen |
| O | open file |
